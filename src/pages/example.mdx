  ## What is MDX?

  MDX allows you to use **Markdown and JSX together**.

  It's useful for writing documentation, tutorials, blog posts,
  and other content-rich pages.

  You can write regular Markdown:

  - Headings and paragraphs
  - Lists and tables
  - Links and images
  - Code blocks
  - Custom components

  Or use Tailwind classes to style individual elements.
